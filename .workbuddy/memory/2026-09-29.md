## 三相电流采样零点偏置问题（ATK-DMF407 电机板）

- 现象：电机不转时 U/V/W 三相电流读数全为 +0.5A，三相和不为 0（表面违反 KCL）
- 定性：不是 KCL 问题，是三通道共模零点偏置未标定；三相同号同值即为系统性 offset 的证据
- 定量：按板载教程传递关系 AMP_I = 6×(0.02×I) + 1.25V
  - 0.5A 读数 ↔ 输出误差 60mV ↔ 输入折算 10mV ↔ 实际零点约 1.31V（设计值 1.25V）
- 误差来源排序：运放 Vos（TP2412，经噪声增益 7 放大，可达 30~40mV）> VCC1.25 基准精度（近 1:1 传到输出，±25mV）> R11/R25/R26 分压网络 1% 容差（±12~25mV）；R13/R14/R22 失配只影响增益斜率
- 差分放大结构：R13=R14=R25=R26=1K，R22=12K（反馈），R11=VCC1.25 上拉构成抬升网络；信号增益 6，同相噪声增益 (1+R22/(R13+R14))=7
- 待办/建议：上电电机未使能时对每相采 1024 次取平均做软件零点标定；采样必须同一时刻（零矢量）进行，否则运行中三相和也不为 0（采样不同步，非偏置）

### 追加观察（同日）：上电后存在衰减瞬态

- 现象：彻底断电一段时间再上电，电机静止时读数从 1.1A 单调缓降到 0.5A
- 拆分：稳态残差 0.5A（静态零点偏置）+ 上电瞬态约 72mV（时变误差）；1.1A ↔ 132mV 输出 ↔ 22mV 输入折算
- 推论：断电足够久才复现高值 → 被复位的是热时间常数/电荷弛豫状态，非纯逻辑状态
- 嫌疑排序：VCC1.25 抬升源自热漂移 > 运放 Vos 自热漂移（均经 7 倍放大）> RC/介质吸收（R×C≈0.1s，与现象不符）> VDDA 轨建立 > 运放轻振荡（C19 容性负载）
- 判别决策树：上电后每 30s 同步记录 VCC1.25 / AMP_IU / MCU 读数 —— 基准漂→查抬升源；基准稳而 AMP_IU 漂→查运放温度特性；前两者稳而读数漂→查 VDDA 与采样时序
- 结论修正：零点标定必须在**热平衡之后**做，否则会把上电瞬态偏置固化；更稳的方案是仅在"电机停机且三相均判零电流"时用慢速滑动平均做在线零点跟踪
- 待用户补充：衰减时间常数（秒级/分钟级）、最终是否稳定在 0.5A、采样时 PWM 是否在运行
- **后续反馈：漂移"没有任何规律"** → 逻辑上排除热漂移/RC 弛豫（二者必然单调且可重复），主导误差改为随机/时序相关机制
- 新嫌疑排序：①三相采样时刻未与 PWM 同步（软件随机时刻读取，典型 FOC 三电阻采样错误）②功率级开关噪声经有限 CMRR + 地弹耦合 ③驱动全关时相线悬空、采样通道高阻拾扰 ④代码层：offset 变量未初始化 / ADC 校准未等就绪 / 变量被越界覆盖
- 下一步判定手段（改用统计量而非曲线）：通道自检（短接分流两端，输出应恒为 1.25V）、每相采 1024 次统计均值/标准差/峰峰值、硬件 TIM 触发同步采样对比、示波器加 20MHz 带宽限制看直流电平与频谱成分、断开母线分离功率级噪声
- **第三组数据：再次上电变成 0.3A**。三次上电序列 = 0.5 / 1.1→0.5 / 0.3A，全部同为正号，折合输出偏置 36~132mV，输入端折算 6~22mV
- 特征判定：①"每次上电不同、同一轮内三相一致"→ 随机性来自**共享节点或一次性初值**，不是各通道独立噪声；②偏置全是正号且远超典型运放 Vos（几 mV）→ 首疑**抬升基准 VCC1.25 网络**，尤其需确认它由什么产生（LDO / 电阻分压 / MCU 引脚输出），若是 MCU 输出则上电状态未定可解释随机性
- 关键待确认：代码零点来源是硬编码 1.25V 常量，还是上电标定值
- **第四组数据：多次尝试后稳定复现 +0.3A**

### 代码审查结论（已读 adc.c / tim.c / pmsm.c / foc_algorithm.c / main.c）

- **根因确认**：`pmsm.c:71-73` 零点硬编码为 1.25V 常量，**完全没有零点标定**：
  `I_uvw[0] = ((ADC2->JDR1*3.3f/4096.0f)-1.25f)/0.12f;`（v相走 ADC1->JDR1，w相走 ADC3->JDR1）
  +0.3A ↔ 36mV 输出偏置 ↔ 输入端 6mV，正好落在 TP2412 Vos×7（噪声增益 7）与抬升网络容差的正常范围
- **排除项 1（采样同步）**：triple 模式 `ADC_TRIPLEMODE_INJECSIMULT` + TIM1_CC4 触发 → 三相同一时刻采样，之前"采样不同步"的怀疑不成立
- **排除项 2（触发点）**：TIM1 中心对齐（CNT_CENTERALIGNED1，ARR=8399，10kHz），CH4 Pulse=8390 → 触发点落在**零矢量中心（计数器峰值）**，且窗口裕量足够；注入采样时间 3 ADCCLK≈143ns，配合 R24=100Ω/C20=100pF 前端足够
- **重大发现：本工程是开环驱动**。`Motor_Run()` 中 theta 以 0.001/中断 软件递增，`Voltage_DQ` 固定 `Vd=0, Vq=1.5`，**采出的三相电流没有参与任何控制环**（无 PI）。因此"电机不转"≠"绕组无电流"——PWM 持续输出 1.5V 幅值电压矢量
- 由此修正标定前提：不能靠"电机不转"当零电流条件，必须让驱动输出**零矢量**（Vd=Vq=0，三相下桥臂全开）或断使能后再采零点
- 建议的最小改动方案（已向用户提出，等确认后再动手）：新增 `float I_offset[3]`，把 71-73 行改为 `(JDR1 - I_offset) * 3.3f/4096.0f/0.12f`；在 Motor_Run 内用计数器实现启动阶段 Vq 临时置 0、累加 1000 次取平均完成标定（改动局限在 pmsm.c）
- 另记：`foc_algorithm.c` SVPWM_Calc 中过调制限幅存在已知 BUG（`Tx /= T` 应改为 `Tx = Tx * Tpwm / T`），代码注释已标注
- 斜率（增益）误差是第二阶段问题：`3.3f` 假设值与实际 VDDA 不符 + 分压网络容差

### 追加：Id/Iq 理论预期推导（开环 Vd=0 / Vq=1.5）

- ωe 计算：θ 步进 0.001 rad / 中断，中断周期 = PWM 周期 = 100µs（TIM1 中心对齐 ARR=8399 @168MHz = 10kHz）→ **ωe = 10 rad/s = 1.59 Hz**（周期 0.63s）。ωe·L ≈ 0.01Ω，远小于 R，可按纯电阻处理
- 静止/堵转稳态（软件 dq 系）：`Vd = R·Id − ωeLq·Iq`、`Vq = R·Iq + ωeLd·Id`
  → **预期 Id ≈ 0，Iq ≈ 1.5 / R_phase**（R=2Ω→0.75A；R=5Ω→0.30A；R=10Ω→0.15A）
- 若转子真跟随同步旋转，反电动势 ωe·ψf 会抵消部分电压，Iq 略小于 1.5/R
- SVPWM 缩放核对：Tx/Ty 与标准式符号相反（扇区/旋向约定不同），幅值一致；线性区上限 |V| ≤ Udc/√3 = 13.86V，Vq=1.5 约 11% 调制
- **零点偏置在三相 abc 叠加 Δ 时对 dq 的影响（关键判据）**：Clarke 后成 αβ 平面固定矢量 → Park 后成 dq 平面幅度 2Δ 的旋转矢量
  `Id = A·sinφ + 2Δ·sin(θ+30°)`，`Iq = −A·cosφ + 2Δ·cos(θ+30°)`
  → 若 Δ=0.3A，Id/Iq 上会叠加 **±0.6A、周期 0.63s 的缓慢正弦纹波**；无偏置则 Id/Iq 为稳定直线
- 由此得出决定性判据：Id≈0 且 Iq 为 DC → 无公共偏置（0.3A 是真实电流，需推翻此前"偏移"结论）；Id/Iq 带 0.63s 正弦 → 公共偏置确认
- 待用户提供：电机相电阻 R（量线电阻÷2）、Id/Iq 是否随时间缓慢摆动
- **第五组数据：实测 Iq ≈ 4A**

### Iq≈4A 的定量核对（与已知条件冲突）

- 硬约束：等幅值 Clarke/Park 下 `√(Id²+Iq²) ≡ 三相电流幅值`。Iq=4A ⇒ 相电流幅值 ≥4A，与用户此前所述"每相 +0.3A"直接矛盾，两者必有一错
- 从占空比反算激励：θ=0 时 Tcmp=(4200,3745,4655)/ARR8399 → 线电压≈1.3V，相位电压幅值≈1.5V（Vq=1.5 确实生效，验证 SVPWM 缩放无误）
- 若 Iq=4A 为稳态真值 → 等效 R = Vq/Iq = **0.375Ω**，铜耗 3I²R ≈ 18W
  - 云台/小功率 BLDC（R=5~15Ω）→ 理论 Iq 仅 0.1~0.3A
  - 航模低阻无刷（R=0.05~0.2Ω）→ 理论 Iq 可达 7~30A
- 最干净的判据：**三相电流之和**。公共偏置 Δ 留下恒定 3Δ，真实电流三相和恒为 0
- 需用户补充：实测相电阻、Ia/Ib/Ic 原始打印值（恒定 or 摆动、摆幅、三相和）、电机是否发热

### 用户提出"应该做采样校准"——已确认方案

- 用户自行得出正确方向：应在采样时做零点校准。确认可行，但需澄清偏置来源
- 偏置来源澄清：F4 的 SAR ADC 本体直流失调 < 1 LSB（≈0.8mV），可忽略；真正的偏置来自**模拟通道**（TP2412 的 Vos 经 7 倍噪声增益放大 + VCC1.25 抬升网络容差）。对策相同（零电流下测一次减掉），但它决定了**标定时模拟通道必须处于与正常工作时相同的状态**（下桥臂导通、共模≈0V），因此方案 A（零矢量）优于方案 B（PWM 全关）
- 硬件注入偏移寄存器 `ADC_JOFRx`（HAL 的 `InjectedOffset`）只能以 1 LSB（0.8mV）为步进，无法校亚 LSB；软件标定可做到亚 LSB，**推荐软件标定**
- 已给出最小改动方案（待用户确认后动手）：
  - `pmsm.c` 新增 `float I_offset[3]` + `#define CALIB_NUM 256`
  - `Motor_Run()` 内：`cnt < CALIB_NUM` 时强制 `Voltage_DQ.Vq = 0`（零矢量）并累加三相 JDR1；采满后求平均写入 `I_offset[]`，恢复 `Vq = 1.5f`
  - 三行换算改为 `(ADCx->JDR1 - I_offset[x]) * 3.3f / 4096.0f / 0.12f`
  - 关键细节：`SVPWM_Calc` 的 `switch(sector)` 没有 `case 0`，所以 Vq=0（Valpha=Vbeta=0 → sector=0）时 `rtY.Tcmp1/2/3` **不会被更新**、保持初值 0 → CCR=0 → 下桥全开、上桥全关 = 零矢量 000，恰好是理想的零电流状态（这是一个可利用的巧合，也说明该 switch 缺少 default 赋值是个隐患）
  - 标定耗时 256×100µs ≈ 26ms，上电瞬间完成
- 验证指标：标定后打印 `I_offset[]` 原始码，预期应在 1551 附近（1.25V/(3.3/4096)）；若明显偏离（如 >1600，对应偏置 >40mV）说明模拟通道零点偏得厉害，值得回头查硬件
- 局限性说明：零点标定只消掉截距；增益（斜率）误差仍在（`3.3f` 与实际 VDDA 不符、分压网络容差、R_shunt 容差），表现为非零电流时的比例误差
